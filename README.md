# finance-manager
finance-manager

1. Account dashboard
   View the current balance, total income, total expenses and monthly summaries.



2. Transaction management
   Create, edit, delete and list income and expense transactions.



3. Categories
   Categorize transactions such as food, transport, rent, salary and entertainment.



4. Financial reports
   Filter transactions by date and category and compare monthly income and expenses.



5. User authentication — later stage
   Give each user a private account and ensure that users can only access their own financial data.
